# 2026-10-19 — 修复前端主流程端点未挂载（P0）

## 背景

分析项目时发现：`main_fastapi` 只按 `api.__all__` 挂载路由，而前端唯一入口
`web/index.html` 调用的步进式流水线端点来自 `api/topic_pipeline_api.py` ——
该模块从未登记进 `__all__`。结果首页"题材全自动生成"和管道页（脚本→配音→渲染）
的所有请求都落空，且未注册的 `/api/*` 被 SPA fallback 返回 200 + `{"detail":"Not Found"}`，
前端连失败都识别不出来。

## 完成事项

- `api/topic_pipeline_api.py`：移除与统一入口重复的 `POST /api/topic/generate`
  （两者路径冲突，且前者是新统一入口），保留 SSE 流式生成与 `/api/topic/videos/*`
- `api/__init__.py`：登记 `topic_pipeline_api`，路由数 106 → 118
- `api/topic_video_api.py`：`topic` 入参兼容旧字段 `topic_keyword`
- `main_fastapi.py`：未注册的 `/api/*`、`/static/*` 显式返回 404
- 新增 `tests/test_frontend_api_contract.py`（4 条）：
  - 解析前端所有 `API + '...'` 调用并断言全部已注册（本次问题的通用回归）
  - 主流程关键端点显式守护
  - 未注册 API 返回 404
  - 解析器本身的有效性守卫（>=15 个接口）

## 验证

- 端到端（TestClient + 打桩 LLM/选题）：
  `POST /api/topic/generate/stream` → `progress/thinking/done` SSE 正常，
  落库 `topic_videos`，`GET /api/topic/videos/{id}/status` 返回 `script_ready`；
  未注册 API 返回 404；`GET /` 返回 SPA
- 全量离线测试：`770 passed, 3 failed, 2 skipped`（改动前 764 passed / 5 failed）

### 剩余 3 个失败：Playwright 浏览器未安装

| 测试 | 原因 |
|---|---|
| `tests/template/test_html_generator.py::test_generate_frame` | `BrowserType.launch: Executable doesn't exist ... chrome-headless-shell.exe` |
| `tests/template/test_integration.py::test_render_image_default_template` | 同上 |
| `tests/template/test_integration.py::test_render_e2e` | 同上 |

修复只需一条命令：`venv\Scripts\python.exe -m playwright install chromium`（约 150MB）。
未安装时 `services/template/browser.py` 会抛 `BrowserNotAvailableError`，
即 HTML 模板渲染（31 个模板、`/api/templates/preview`）在当前机器上不可用。

此前另外 2 条失败（写 `output/ai_cache`、`output/.render_state`）在完全访问模式下已通过，
确认是运行沙箱的路径限制，而非代码问题。

## 环境问题（已处理）

项目从 `D:\Offline-ShortVideo-Agent` 迁到 `D:\Code\Offline-ShortVideo-Agent` 后，
工作区根目录与 `output/` 缺少当前用户的 `WRITE_OWNER`，导致 pwsh/python 无法写盘。
已用权限诊断脚本补上并生成回滚记录（`D:\Code\acl-recovery-offline-shortvideo`）。
